# FAQ

Customers can browse products, add them to cart, create orders from the cart session, and check order progress through the platform services.
Recommendation results are personalized from interaction signals, catalog data, and knowledge graph relations.
Chat answers should stay grounded in product content, policy documents, and verified runtime data from the core services.

When a question requires exact current price, stock, cart state, or order status, the assistant must use realtime API data instead of static retrieval only.
